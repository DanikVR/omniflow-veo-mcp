# OmniFlow MCP — автоматизация Google Flow (Veo 3 / Omni 1.1) из Claude

[English README](README.md)

**У Google Flow нет API.** Этот MCP-сервер даёт Claude Code и Claude Desktop руки внутри Google Flow: пакетная генерация видео на Veo 3 / Omni 1.1, переходы по ключевым кадрам, сшивка сцен, правка готового видео и автоскачивание — на той подписке Google AI, за которую вы уже платите. Без оплаты за секунды и без API-ключей.

> *Вы, в Claude:* «Сделай 40-секундный промо отеля из фото в `C:/promo`, вертикально, в конце логотип».
> *Claude, через OmniFlow:* `flow_status` → `flow_generate` (5 сцен, пары кадров) → `flow_wait`
> ✓ 5 клипов сохранены в `omniflow-out/HotelPromo/`

## Как это устроено

```
Claude Code / Claude Desktop
        │  MCP (stdio, JSON-RPC)
        ▼
  omniflow-mcp  ──  локальный мост 127.0.0.1:8787  ──  файлы → omniflow-out/
        ▲  HTTP, расширение опрашивает раз в несколько секунд
        │
  Расширение OmniFlow  ──►  вкладка Google Flow (labs.google/fx/tools/flow)
```

MCP-сервер (этот репозиторий) — чистый транспорт: пять инструментов и локальный HTTP-мост без единой зависимости. Работу в самой вкладке Flow делает **расширение OmniFlow**: вводит промпты, ставит модель, формат и длину, прикрепляет референсы и ключевые кадры, ждёт рендер и скачивает клипы с понятными номерами. При подключении расширение отдаёт мосту свой *режиссёрский плейбук* (карта драматургии, движения камеры, продуктовые приёмы, рецепт сшивки, слои звука); `flow_status` передаёт его Claude — поэтому Claude ведёт себя как режиссёр, а не как наборщик текста.

## Быстрый старт

**1. Поставьте расширение** — [OmniFlow в Chrome Web Store](https://chromewebstore.google.com/detail/omniflow-%E2%80%94-mcp-for-google/kljcdogggnjabpcffmbjbpaeahmkinik). Первые 24 часа бесплатно, без ключа и карты.

**2. Добавьте MCP-сервер.**

Claude Code:

```bash
claude mcp add omniflow -- npx -y omniflow-mcp
```

Claude Desktop — в `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "omniflow": { "command": "npx", "args": ["-y", "omniflow-mcp"] }
  }
}
```

**3. Откройте Google Flow** — [labs.google/fx/tools/flow](https://labs.google/fx/tools/flow) — и войдите в проект. Значок расширения в панели Chrome покажет *Claude ✓*, когда мост на связи.

**4. Говорите с Claude.** Он задаст два-три коротких вопроса (цель, площадка, материалы), предложит сценарии и снимет:

```
Сделай 30-секундную рекламу термокружки, вертикально. Фото в D:/mug. В конце логотип.
```

Клипы складываются в `omniflow-out/<папка>/` рядом с тем местом, откуда запущен Claude (переопределяется переменной `OF_OUT`).

## Инструменты

| Инструмент | Что делает |
|---|---|
| `flow_status` | На связи ли расширение, открыт ли проект Flow, что в очереди — и `extension.director`, плейбук, которому следует Claude. Вызывается первым. |
| `flow_generate` | Ставит в очередь один или много клипов: промпт, модель, формат, длина, варианты, референсы, пара ключевых кадров, сшивка, ассеты библиотеки. Сразу возвращает `jobId`. |
| `flow_wait` | Ждёт задание и возвращает пути к файлам. Опрос раз в 5 с, до `timeoutSec`. |
| `flow_edit` | Правка последнего готового клипа в редакторе Omni 1.1 (video-to-video): фон, погода, свет, убрать объект, стилизация. |
| `flow_cancel` | Убирает из очереди всё, что ещё не начало рендериться. |

Полный справочник параметров: [docs/tools.md](docs/tools.md). У моста есть и обычный HTTP API на `127.0.0.1:8787` (`/health`, `/jobs`, `/jobs/:id`, `/cancel`) для скриптов, которые не умеют MCP.

## Скиллы Claude

В `skills/` два скилла Claude Code, которые делают из Claude режиссёра Flow:

- **omni-director** — включается всегда, когда пользователю нужно видео: задаёт правильные вопросы, выбирает движения камеры и продуктовые приёмы, сшивает сцены, после рендера предлагает правки.
- **ad-video** — одна строка заказа → раскадровка → пары ключевых кадров → английские промпты → `flow_generate` / `flow_wait`.

Скопируйте их в `.claude/skills/` проекта (или в `~/.claude/skills/` для всех проектов).

## Безопасность

- Мост слушает только `127.0.0.1`. Чтобы дотянуться с другой машины (Tailscale и т. п.), задайте `OF_HOST` и `OF_PORT`; тогда каждый запрос обязан нести токен из `~/.omniflow-token` (заголовок `x-omniflow-token`).
- К мосту допускаются только источники `chrome-extension://`; всё остальное получает 403.
- С вашей машины ничего не уходит, кроме того, что само расширение отправляет в Google Flow. Промпты и клипы остаются на диске. На lingoflow.pro расширение ходит только за проверкой ключа.
- Расширение нажимает те же кнопки, что и вы, с паузами 25–70 секунд. Никаких обходов капчи, приватных API и мультиаккаунтов.

## Вопросы

**Работает без расширения?** Нет. MCP-сервер — транспорт; генерация идёт в вашей вкладке Google Flow через расширение.

**Расширение бесплатное?** Первые 24 часа после установки — без ключа. Дальше бесплатная неделя с картой, затем €29 в год или €79 навсегда. Цены — на [странице продукта](https://lingoflow.pro/omniflow?utm_source=github&utm_medium=readme_ru&utm_campaign=omniflow-mcp#pricing).

**Мост на одной машине, Claude на другой?** Да: `OF_HOST=0.0.0.0 OF_PORT=8787 npx omniflow-mcp` на машине с Chrome, в настройках расширения указать адрес моста и токен.

**Куда падают файлы?** В `omniflow-out/` текущего каталога, либо `OF_OUT=/путь`.
